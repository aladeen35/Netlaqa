# Motion – معلومة جودة سريعة

فيديوهات موشن جرافيك (1080×1080، 17 ثانية) لنشرها على LinkedIn. كل فيديو يحتوي معلومتين، واللوقو ثابت أعلى اليسار طوال الفيديو.

- أضف المعلومات في `tips.json` (كل فيديو = معلومتان: `title` و`highlight` و`body`).
- `python3 render.py` يصدّر كل الفيديوهات إلى `output/`.
- `python3 render.py --id 02` يصدّر فيديو واحداً، و`--preview 02` يحفظ لقطات PNG فقط.

يحتاج Python و Pillow (مع raqm) و ffmpeg.
